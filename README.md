# SafeFusion

> 语义检索 + 关键词规则双通道融合的多模态违规内容识别引擎（文本 / 图片）

## 状态

🚧 **需求评审阶段** — PRD 定稿前不含业务代码。架构与功能范围以 `开发/v0.1/prd.md` 定稿为准。

## 计划能力（草案，以 PRD 为准）

- **关键词通道**：基于规则词库的精确 / 模糊命中检测
- **语义通道**：向量检索相似违规语义，捕捉变体与隐晦表达
- **融合决策**：双通道结果加权裁决，输出风险分级与命中依据
- **多模态**：文本直接检测；图片经 OCR / 向量化进入同一管线（范围以 PRD 为准）
